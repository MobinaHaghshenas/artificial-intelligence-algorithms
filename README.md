# Artificial Intelligence Algorithms

Python implementations of classical Artificial Intelligence search and optimization algorithms. This repository contains coursework projects focused on adversarial search and heuristic optimization.

## Projects

| Project | Algorithms | Description |
|---|---|---|
| [Tic-Tac-Toe AI](./tic-tac-toe-minimax/) | Minimax, Alpha-Beta Pruning | A terminal-based Tic-Tac-Toe game in which the AI evaluates possible moves using adversarial search. |
| [Predator–Prey Ordering Optimization](./predator-prey-ordering-optimization/) | Genetic Algorithm, Simulated Annealing | Two metaheuristic approaches for finding an ordering of vertices in a directed graph that satisfies as many predator-before-prey constraints as possible. |



## Skills Demonstrated

- Adversarial search: Minimax and Alpha-Beta Pruning
- Heuristic and metaheuristic optimization
- Permutation-based search spaces and fitness evaluation
- Python programming and algorithmic problem-solving
- Comparing algorithmic approaches using objective-function scores

## Getting Started

Each project has its own README with its problem description, implementation details, and run instructions. Open the relevant project folder and follow its instructions.

## Notes

These are educational implementations. Results depend on the problem definition, input data, and algorithm parameters. Performance comparisons should be based on repeated runs and consistent evaluation criteria rather than a single run.
